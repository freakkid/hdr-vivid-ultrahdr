# 鸿蒙手机（HarmonyOS NEXT）安装本 APK

> 更正记录：早期文档曾断言「纯血鸿蒙装不了 APK，只能走 .hap」——**这个结论是错的**。
> 准确说法是：HarmonyOS NEXT 原生不解析 APK，但可以通过「卓易通」这一兼容容器安装运行。
> 华为官方支持页面亦确认该渠道，见文末来源。

## 1. 原理：为什么能装

| 层 | 谁提供 | 能否直接跑 APK |
|---|---|---|
| HarmonyOS NEXT 原生 | 华为 | ❌ 只认 `.hap` |
| 卓易通（第三方容器，iSulad 沙箱） | 卓易通（应用市场可下） | ✅ 在容器内跑 Android |
| 出境易 | 第三方 | ✅ 但偏海外应用，本地 APK 导入受限 |

两者都是**应用层容器**，不是系统内置兼容层。所以：APK 能装、能跑，但与鸿蒙原生应用相互隔离。

## 2. 前置：确认已装卓易通

华为应用市场 → 搜索「卓易通」→ 安装（首次启动会部署运行环境，约 2–3 GB，需留足空间）。
桌面图标右下角带「卓」字的应用，表示运行在容器内。

本机（PC）**不需要**任何驱动、adb 或 hdc。`HDC Device` 出现在设备管理器只说明数据线通道存在，
与能否装 APK 无关。

## 3. 把 APK 送到手机（三条通道，任选）

APK **不在仓库里**（`.gitignore` 排除了 `*.apk`），需本地构建：
`cd src/android && ./gradlew assembleDebug`，产物在
`out/HdrVividUltraHdr-0.1.5-debug.apk`（约 2.2 MB）。

### 3.1 微信（最省事）

1. 电脑微信 → 文件传输助手 → 把 `.apk` 拖进去发送
2. 手机微信收到后点开 → 「用其他应用打开」/「保存」

> **必踩的坑**（华为官方明确说明）：微信会给安装包文件名自动加 `.1`。
> 此时直接点无法安装，需要：
> 桌面 → **文件管理** → 最近 → 长按该文件 → **重命名** → 把结尾的 `.1` 删掉，恢复成 `.apk`。

### 3.2 卓易通「+」号本地安装（推荐，跳过重命名）

1. 先把 APK 存到手机（微信/QQ/网盘均可）
2. 打开**卓易通** → 首页右上角 **「+」** → 选 **「本地安装包」**
3. 选中刚存的 APK → 安装

### 3.3 文件互传（最稳，路径固定）

1. 把 APK 放到手机 `文件管理 → 我的手机 → ShareData → ShareFile`
2. 打开卓易通 → 文件互传 / 本地文件 → 进入该目录 → 点 APK 安装

## 4. 装好后的验收顺序

1. 桌面出现「HDR Vivid 导出器」（图标可能带「卓」字）
2. 打开 → 应显示两个按钮：「选择 HDR 照片并导出」「以文件发送」（后者初始为灰）
3. 选图 → 界面逐行打印：
   - `容器：ISO_ULTRA_HDR` / `CUVA` / `PLAIN_JPEG`
   - `增益图：有（xxxxxx B）` 或 `无`
   - `validate: ok=true errors=0`
   - `已写出：IMG_xxx_HDR.jpg`
4. 判定标准是**自检全过**，不是「能导出文件」

## 5. 已知风险（容器环境的真实限制）

| 风险 | 原因 | 对策 |
|---|---|---|
| 选图器看不到相册里的照片 | 容器有独立文件系统，系统的 Photo Picker 未必透传 | 先把照片导入容器（ShareFile），再在 App 内选 |
| 「以文件发送」唤不起分享面板 | 容器对 Android 的 `ACTION_SEND` 支持不完整 | 导出文件后用文件管理取出，或在容器内直接查看 |
| 安装被拦「签名校验失败」 | 本 APK 为 debug 签名，容器策略可能拒绝 | 在卓易通内装 **Apktool M** → 点 APK → 「删除签名验证」生成 `_kill.apk` → 装该文件；仍不行则用「快速编辑」改包名（每个点号后加字符） |
| 首次启动很慢 | 容器冷启动 | 属正常，第二次起变快 |
| 导出大图卡顿 | 容器内 CPU/内存受调度限制 | 先在相册把源图裁剪小一些，或等后续加「长边」选项 |

## 6. 如果你更想走原生 .hap

需要付出这些成本，非必要不建议：

| 项 | 要求 |
|---|---|
| 工具 | DevEco Studio（4–8 GB）+ hvigor + ohpm |
| 账号 | 华为开发者账号 + **实名认证** |
| 签名 | 调试证书 + Profile，且 Profile 必须**登记设备 UDID** |
| 现状 | 仓库 `src/ets/`、`src/harmony/` 共 8 个文件约 1737 行，**无工程脚手架**，不可构建 |
