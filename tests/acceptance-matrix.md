| ID | 用例 | 输入 | 期望 | 结果 |

| U-01 | 几何：裁剪 + 缩放到 2048 | 4000×3000，crop(100,100,3000,2000) | outW/outH 取偶且长边 ≤2048；gainOutW=ceil(outW/4) 取偶 | ☐ |

## 3. L2 Golden-file 结构比对（CI 必跑）

对同一张样张重复导出 3 次：

| 检查 | 期望 |
|---|---|
| 段顺序 | APP0 → APP1(XMP) → APP1(EXIF?) → APP2(ICC) → APP2(MPF) → SOS → 主图 → 增益图 |
| 字节稳定性 | 3 次导出完全相同（同参数下确定性） |
| 增益图位置 | 位于主图 EOI 之后、文件 EOI 之前 |
| MPF offset | 两个 entry 的 offset 均 > 主图 SOS 位置 |
| 文件大小波动 | < 1% |

### 4.2 量化门禁

| ID | 指标 | 阈值 | 方法 |
|---|---|---|---|
| AC-1a | SDR 端 ΔE2000 均值 | < 3 | 与源 SDR 基图逐像素比较（sRGB 8bit） |
| AC-1b | SDR 端 ΔE2000 P99 | < 6 | 同上 |
| AC-1c | 黑位偏移 | ≤ 2/255 | 取画面最暗 1% 区域均值 |
| AC-1d | clipping 增量 | < 0.5% | 统计 250 以上像素占比变化 |
| AC-2a | HDR 端高光提升 | 峰值可达 SDR 白的 2 倍以上 | 用不同 max_display_boost 渲染比对 |
| AC-2b | HDR 端 ΔE2000（SDR 范围内像素） | < 5 | 只统计 gain≈0 区域 |
| AC-4a | 增益图/主图比例误差 | = 0（精确整数档） | validator A3 |
| AC-4b | 棋盘格边缘错位 | 0 像素偏移 | 目视 + 边缘梯度互相关 |
| AC-5 | 增益图通道数 | = 1 | validator A4 |

## 8. 已知会导致"必须回滚"的信号

| 信号 | 含义 |
|---|---|
| 任一不支持端出现整体发灰 | 主图传输函数或 ICC 错误 —— 最严重，用户一眼可见 |
| validator 通过但 Android 相册不显示 HDR | XMP/MPF 结构与系统解析器不兼容 |
| 部分解码器崩溃（而非忽略） | MPF 字节结构有误，可能被判定为恶意构造 |
| 增益图出现可见分块/马赛克 | 增益图质量或分辨率不足 |
| 旋转后高光位置偏移 | 几何变换未同步 |
